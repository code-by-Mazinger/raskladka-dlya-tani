# Уютная раскладка

Пасьянс вроде косынки, только вместо мастей — категории предметов. Спокойный: без лимита ходов и без проигрышей.

Играть: https://code-by-mazinger.github.io/raskladka-dlya-tani/ — на iPhone лучше сохранить на экран «Домой» (Поделиться → На экран «Домой»).

## Правила
- Внизу столбцы, как в косынке: закрытые карты, сверху открытая. Справа вверху колода: нажала — открылась карта; кончилась — колода переворачивается.
- В пустую ячейку кладётся карта-категория («Одежда 0/4»), на неё — её предметы. Собраны все — категория уходит, ячейка свободна.
- В столбцах на открытую карту кладутся карты той же категории; категорию — только в пустой столбец.
- Нажми карту — она сама уходит в подходящее место. Отмена хода и подсказка бесплатны; если ходы кончились — «Перемешать».

## Сложность
- 1–5 — лёгкие. С 6-го по 45-й растёт: категорий 4 → 8 (по 4, 6, 8 карточек), ячеек меньше, чем категорий, карты-категории чаще лежат закрытыми.
- Раздача подбирается по доле побед «наугад»: от ~90% на 6–15-м до ~45% к 45-му. Проходимость гарантирована: подсказка с первого хода ведёт к победе.
- Проигрыша нет: в тупике «Перемешать» раскладывает стол заново (ячейки не трогает) — с ним доходит до конца 100% партий.

## Фишки
- **Уютный дом** — каждая раскладка добавляет вещь в комнату на главном экране (24 вещи).
- **Мои категории** — свои категории из 3–8 предметов, можно с эмодзи; «Сыграть с моими».
- **Минута дыхания** — вдох 4 с, выдох 6 с, шесть раз.
- **Ночь и тихий звук** — тёмная тема сама с 21 до 7 (или вручную), звук по умолчанию негромкий.
